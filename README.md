## ✅ Como Usar

1. Abra o arquivo `DASHBOARD_Hipertensos_Diabeticos_SM.xlsx`
2. Acesse a aba **Cadastro** e preencha os dados do paciente a partir da linha 6
3. Na coluna **Condição**, use a lista suspensa para selecionar o tipo
4. Informe as datas de receita no formato `DD/MM/AAAA`
5. As colunas **Próx. Troca** e **Status** serão atualizadas automaticamente
6. Acesse a aba **Dashboard** para visualizar o resumo geral

> ⚠️ **Atenção:** Não altere as colunas com fórmulas (Idade, Próx. Troca, Status). Esta planilha é para uso interno da UBS. **Proibida a distribuição e comercialização.**
